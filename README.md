# WANGAN BASE

走るほど、つながる。湾岸プレイヤーのための非公式攻略コミュニティです。

## 主な機能

- ストーリー進捗と次の目標を表示するマイガレージ
- コース攻略・車種データ
- 攻略情報、質問、対戦募集のコミュニティ投稿
- ブラウザ内への進捗・投稿保存
- スマートフォン対応

## 開発

```bash
npm install
npm run dev
```

ビルド確認は `npm run build`、静的解析は `npm run lint` を使用します。

# WANGAN BASE

湾岸ミッドナイト マキシマムチューン 6RR PLUS を遊んだ記録を、運営者ひとりが書いていく非公式サイトです。掲示板や会員制度はありません。

## 方針

載せてよいのは、公式が公表している情報と、運営者自身が実際に確認したことだけです。

2026年9月2日に、初期表示として持っていた架空のデータをすべて削除しました。削除したのは、架空のドライバー名とストーリー進捗、「128 DRIVERS ONLINE」という固定のオンライン人数、投稿3件とその投稿者名・いいね数・投稿時刻、車種投票の得票数、貢献ドライバーのランキング、月額390円の会員制度、未登録のBOOTH商品です。実在しない利用者がいるように見せることになるためです。

同じものを再び追加しないでください。数字を置きたくなったら、その数字の出どころが公式か自分の記録かを先に確認します。

## 主な機能

- 運営者の現在の進捗を書く「いまの状況」
- 収録コース・車種の名称一覧（性能の比較や推奨設定は載せない）
- 全国の湾岸ミッドナイト マキシマムチューン 6RR PLUS 公式設置店一覧への都道府県別リンク
- 閲覧者が自分用に進捗をメモする欄（端末内のみに保存し、送信はしない）
- スマートフォン対応

## 開発

```bash
npm install
npm run dev
```

ビルド確認は `npm run build`、静的解析は `npm run lint` を使用します。
